# ATM Machine - Python

A simple console-based ATM Machine program created using Python and Object-Oriented Programming (OOP) concepts.

## Features

- Create a PIN
- Change PIN
- Check account balance
- Withdraw money
- Exit the program

## Technologies Used

- Python
- Object-Oriented Programming (OOP)

## How to Run

1. Download or clone this repository.
2. Make sure Python is installed on your computer.
3. Run the following command:

```bash
python atm.py
```
## Learning Purpose

This project was created as a beginner Python project to practice:

- Classes and Objects
- Constructors
- Methods
- Variables
- Conditional Statements
- User Input
- Basic ATM operations
